# Controle de Missão Espacial

Projeto desenvolvido para a disciplina Advanced Programming And Mobile Dev.

## Descrição

Solução integrada para controle de missão espacial, composta por:

- Backend em Java com Spring Boot
- Aplicativo mobile em React Native com TypeScript
- Banco de dados H2 em modo file
- Integração entre frontend e backend utilizando requisições GET e POST
